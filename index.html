VYPAR / SYSTEM SPEC

Vypar: voice first ERP on WhatsApp

Full stack ERP for Indian retail owners covering stock, credit ledger (khata), and sales reporting.

  1. 01 / INGEST. WhatsApp webhook captures voice notes in Telugu, Hindi, Tamil, and 20 plus regional languages.
  2. 02 / TRANSCRIBE. Sarvam AI maps audio to native text and a standard schema.
  3. 03 / ROUTE. LangGraph directs intent to inventory, ledger, or billing tools.
  4. 04 / GUARD. Quantity checks, stock boundaries, and write constraints enforced.
  5. 05 / STORE. MongoDB atomic updates with geospatial shop tagging.
  6. 06 / REPLY. Localized audio confirmations or invoices return in chat.
SAATHI / SYSTEM SPEC

Supply Chain Saathi: reverse auctions on WhatsApp

Procurement agent connecting retail demand with nearby supply, priced in real time.

  1. 01 / REQUEST. Retailer posts requirement with live location.
  2. 02 / DISCOVERY. MongoDB 2dsphere query finds wholesalers inside the delivery radius.
  3. 03 / DISPATCH. FastAPI sends concurrent quote invitations over the WhatsApp API.
  4. 04 / AUCTION. LangGraph and Gemini Flash normalize quotes and rank bids live.
  5. 05 / AWARD. Retailer confirms the best bid in one tap.
CLARITYAI / SYSTEM SPEC

ClarityAI Engine: conversational BI with guardrails

Natural language questions compiled into safe SELECT statements and live charts.

  1. 01 / INGEST. Schema metadata becomes a column dictionary.
  2. 02 / COMPILE. LangGraph and Sarvam produce PostgreSQL SELECT statements.
  3. 03 / GUARD. AST validation blocks DROP, INSERT, UPDATE, and DELETE.
  4. 04 / EXECUTE. Sanitized query runs read only with a strict timeout.
  5. 05 / VISUALIZE. Apache ECharts renders charts and summaries live.
