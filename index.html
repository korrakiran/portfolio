SYSTEM SPECIFICATION // VYPAR WHATSAPP ERP

VYPAR — WhatsApp Voice-First ERP Architecture

Full-stack ERP system built for Indian retail store owners, allowing them to manage daily stock, credit ledger (khata), and sales reporting directly via voice notes and text messages on WhatsApp.

01 · INGEST
Voice Ingest: WhatsApp Webhook captures incoming voice notes (.ogg/opus) in Telugu, Hindi, Tamil, and 20+ regional Indian languages.
02 · STT
Sarvam AI Speech-to-Text: Audio is transcribed into native text transcript and mapped to standard schema representations.
03 · GRAPH
LangGraph State Orchestrator: Routes user intent (Inventory check, Khata ledger update, invoice generation) to corresponding tool handlers.
04 · GUARD
Guardrails: Verifies numerical quantities, validates stock boundaries, and enforces database write constraints.
05 · DB
MongoDB State Store: Atomic document updates with geospatial shop location tagging for regional retail management.
06 · OUT
Localized Output: Returns localized audio confirmations or generated invoice receipts via WhatsApp API.
SYSTEM SPECIFICATION // SUPPLY CHAIN SAATHI

Supply Chain Saathi — B2B Reverse Auction Architecture

WhatsApp-native procurement agent automating discovery and price negotiations between local retailers and regional wholesalers.

01 · REQ
Requirement Post: Retailer sends buy requirement (e.g. 50kg Sona Masoori Rice) with their live shop location.
02 · GEO
Geospatial Query: MongoDB 2DSphere $near index discovers candidate registered wholesalers within delivery perimeter.
03 · DISPATCH
FastAPI Dispatcher: Sends concurrent quotation invitations to matching wholesalers via WhatsApp API.
04 · AUCTION
LangGraph & Gemini Flash: Normalizes incoming quotes, evaluates delivery times, and ranks bids in real time.
05 · CONFIRM
Purchase Order: Retailer receives ranked options and confirms the optimal bid with a single tap.
SYSTEM SPECIFICATION // CLARITYAI ENGINE

ClarityAI Engine — Conversational BI & SQL Guardrails

Natural language business intelligence system that converts conversational questions into safe SQL SELECT queries with strict read-only execution.

01 · INGEST
Schema Ingestion: Ingests relational schema metadata and builds column dictionary for SQL compilation.
02 · TRANSLATE
LangGraph & Sarvam: Converts user queries into PostgreSQL SELECT statements with semantic joins.
03 · GUARD
AST Guardrails: Strict AST validation enforces read-only operations, blocking any DROP, INSERT, UPDATE, or DELETE instructions.
04 · EXEC
Query Execution: Runs sanitized query on read-only PostgreSQL instance with a strict execution timeout.
05 · VIZ
Apache ECharts Stream: Renders dynamic bar charts, line graphs, and summaries on the dashboard interface.
